Кейс · перевозки и документооборот

Из папок с копиями — в приложение в телефоне

Документооборот транспортной компании в два шага. Договор, счёт, акт и акт приёмки — без копирования старых файлов. Сначала навела порядок в Google Таблице, потом на той же базе сделала приложение.

Задача

Один и тот же пакет бумаг на каждый рейс

Небольшая транспортная компания: автобусы, рейсы по договорам с организациями. На каждый рейс — договор, счёт, акт, а для постоянных заказчиков — акт приёмки за месяц по дням.

Как было

  • Папка на каждого заказчика, внутри год, внутри копии копий
  • Новый договор — копия прошлого с ручной заменой реквизитов, дат и сумм
  • Кто оплатил, а кто нет — в голове или в отдельном списке
  • Найти документ полугодовой давности может только тот, кто его сохранял
Шаг 1

Google Таблица — порядок без новой программы

Справочник контрагентов

Реквизиты вносятся один раз, дальше подставляются сами.

Договор одной кнопкой

По шаблону, сразу в реестре со ссылкой.

Счёт и акт одной формой

Нумерация и сумма прописью — автоматически.

Акт приёмки по дням

С учётом праздников и переносов по производственному календарю.

Файлы по папкам сами

Каждый документ ложится в папку «заказчик / год».

Захотелось большего

Таблица заработала — и пришёл аппетит: документы с телефона, статусы и оплаты на виду, история исправлений.

Шаг 2

Приложение — компьютер и телефон

На той же базе. На телефоне — иконка на экране «Домой», открывается как обычное приложение, вход по коду.

На всех экранах — демонстрационные данные.

Надёжность

Данные принадлежат владельцу

Всё хранится в аккаунте владельца. Свой сервер не нужен, платы за рабочие места нет, у каждого свой код входа, копия базы — каждую неделю.

Кому подойдёт

Всем, у кого на каждую сделку — один пакет документов

Перевозки, услуги по договорам, аренда техники, монтаж и сервис. Кому-то хватит таблицы, приложение можно сделать потом на той же базе.
